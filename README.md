# GONER CHESS 004 — настоящий Stockfish 19 на Android по HTTPS

## Состав

```
index.html                         приложение (доска, анализ, диагностика)
engine/stockfish-19-lite-single.js   официальный Stockfish.js 19.0.1 Lite Single (без изменений)
engine/stockfish-19-lite-single.wasm официальный WASM (без изменений)
engine/Copying.txt                 GNU GPL v3
manifest.webmanifest, sw.js, icons/  PWA и офлайн-кэш (включаются только после успешного запуска движка)
_headers                           MIME-типы для Netlify / Cloudflare Pages (GitHub Pages его игнорирует)
SHA256SUMS.txt                     контрольные суммы
```

## Почему в 003 был таймаут UCI

В 003 движок запускался из `blob:` URL (`new Worker(blobUrl)`), а путь к WASM подменялся через `self.Module.locateFile`.
Обёртка Stockfish.js 19 **не читает `self.Module`**. Путь к WASM она вычисляет сама: берёт `#хэш` из адреса воркера или строит адрес как `location.origin + location.pathname` с заменой `.js` на `.wasm`.
У blob-воркера `pathname` — это весь адрес целиком, поэтому получалось `https://сайтhttps://сайт/uuid`. `fetch` падал внутри воркера без сообщения в `onerror`, движок не печатал ни строки, и через 20 секунд приложение писало «не ответил на UCI».
Сообщение «Движок загружен и сохранён» означало только то, что файлы попали в IndexedDB. Браузер и Web Worker тут ни при чём.
Ошибка воспроизведена в Chrome с настоящими файлами: внутри blob-воркера вычисляется адрес
`http://127.0.0.1:8765http://127.0.0.1:8765/<uuid>`.

## Что изменено

- Движок запускается **с того же сайта** по документированной схеме: `new Worker('engine/stockfish-19-lite-single.js')`, WASM лежит рядом. Нет blob, CDN, IndexedDB и подмены путей.
- Перед запуском проверяются оба файла: HTTP-статус, MIME, размер (совпадает с релизом 19.0.1), сигнатура `\0asm`.
- Честный handshake: `uci → uciok` (таймаут 45 с на первый запуск), `isready → readyok`, затем самопроверка `position startpos moves d2d4` + `go movetime 500`. Полученный `bestmove` сверяется с легальными ходами чёрных. Статус «РАБОТАЕТ» появляется только после этого.
- Раскрывающаяся «Диагностика движка»: протокол, `isSecureContext`, `crossOriginIsolated`, поддержка Worker/WASM, ответы сервера по файлам, время uciok/readyok/bestmove, `worker.onerror`/`messageerror`, последние строки UCI. Есть кнопки «Копировать лог» и «Перезапустить движок». При ошибке панель открывается сама и показывает точную причину (например, «HTTP 404 для engine/…wasm» или «страница открыта как файл»).
- Устаревший анализ отменяется: на каждую позицию отправляется `stop`, следующий `go` уходит только после `bestmove` предыдущего. Строки `info` от отменённого поиска и от другой позиции не показываются. Если `bestmove` не пришёл, срабатывает сторожевой таймер и движок один раз перезапускается автоматически.
- FEN проверяется строже: пешки на 1/8 горизонтали, лишние фигуры, противоречивые права рокировки и поле взятия на проходе.
- Исправлено смещение стрелок на мобильном (в 003 был дублирующий CSS `inset:11px`). На экранах ≤360 px увеличены клетки.
- Режимы времени: 0,5 / 1,5 / 4 с; MultiPV = 3; оценка и мат (`+M1`) всегда даны с точки зрения белых.
- PWA: Service Worker регистрируется **только после успешной самопроверки онлайн**, после этого движок работает и без сети.

## Публикация с телефона (GitHub Pages, без ПК)

1. Распакуй `GONER_CHESS_004.zip` в «Загрузки» (Файлы → архив → «Извлечь»).
2. В Chrome открой github.com → «+» → **New repository** → имя `goner-chess` → Public → Create.
3. На странице репозитория: **Add file → Upload files** → выбери `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, `SHA256SUMS.txt`, `_headers` → **Commit changes**.
4. Создай папку engine: **Add file → Create new file**, в имени набери `engine/x.txt`, в текст любой символ → Commit. Открой папку `engine` → **Add file → Upload files** → выбери `stockfish-19-lite-single.js`, `stockfish-19-lite-single.wasm`, `Copying.txt` → Commit. Файл `x.txt` можно удалить.
5. Так же создай папку `icons` (`icons/x.txt`) и загрузи в неё три PNG.
6. **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save. Через 1–2 минуты сайт будет по адресу `https://ТВОЙ_ЛОГИН.github.io/goner-chess/`.
   Если кнопок не видно, включи в меню Chrome «Версия для ПК».

**Альтернатива: загрузка ZIP целиком.** Открой `vercel.com/drop` или `app.netlify.com/drop` и выбери **сам ZIP** (`index.html` лежит в его корне). Оба сервиса заявляют, что принимают ZIP, но с Android это не проверялось. Если выбор файла не срабатывает, используй GitHub Pages.

## Проверка на телефоне (2 минуты)

1. Открой HTTPS-адрес в Chrome. Раздел «04 / Движок» должен показать `● STOCKFISH 19.0.1 LITE · РАБОТАЕТ · самопроверка 1.d4 → …`.
2. Разверни «Диагностика движка» и проверь: `isSecureContext: true`, оба файла `HTTP 200`, «размер как в релизе 19.0.1», строки `uci → uciok`, `isready → readyok`, `Самопроверка … ✓`.
3. Нажми «Чёрные», введи 1.d4 касаниями. Должны появиться три линии, стрелки и оценка.
4. Быстро введи несколько ходов подряд: варианты должны относиться к последней позиции.
5. Если что-то не так, пришли скриншот панели диагностики или текст из «Копировать лог».
6. После успешного запуска: меню Chrome → «Добавить на главный экран». Затем проверь в режиме полёта.

## Какие тесты запускались (Chrome 153 headless, эмуляция Android 393×873)

Все с настоящим Stockfish, без моков. Результат: 36/36 на `http://localhost` и 36/36 на `https://localhost` (самоподписанный сертификат).
- `uciok`, `readyok`, `id name Stockfish 19 Lite WASM`; после `d2d4` + `go movetime 500` получен `bestmove d7d5`, ход легален за чёрных.
- Генератор ходов: 20 ходов из начальной позиции, perft(3) = 8902; Kiwipete perft(2) = 2039 и perft(3) = 97862; Position 3 perft(4) = 43238; Position 4 perft(3) = 9467.
- Касаниями проверены рокировка, взятие на проходе, превращение в коня, мат Ra8# с оценкой `+M1`, «Применить лучший ход», отмена хода.
- Знак оценки: у белых лишний ферзь, ход чёрных, я играю чёрными — показано `+8.56`.
- Быстрый ввод 8 ходов: ни одного устаревшего варианта, число `go` равно числу `bestmove`.
- Режимы 0,5 / 1,5 / 4 с; восстановление партии после перезагрузки; ошибочный FEN.
- Ширина 320 / 360 / 393 px: нет горизонтальной прокрутки, стрелки совпадают с доской.
- Офлайн: после регистрации SW сеть отключена, движок стартует из кэша.
- Отказы: без WASM выводится «HTTP 404 для engine/…wasm», для `file://` — «страница открыта как файл — нужен HTTPS-хостинг».

**Не проверено:** реальный Poco M6 Pro / Android Chrome (тестов на физическом устройстве не было), реальный HTTPS-хостинг (GitHub Pages / Netlify / Vercel), установка PWA на домашний экран.

## Происхождение файлов движка

В среде сборки npm-реестр и CDN были недоступны. Файлы взяты из пяти независимых GitHub-репозиториев, где они побайтно совпадают между собой. Размеры совпадают с официальным релизом v19.0.1 (`.js` 28230 байт, `.wasm` 1845971 байт). Заголовок файла — «Stockfish.js 19 (c) 2026, Chess.com», движок отвечает `id name Stockfish 19 Lite WASM`.
SHA-256 смотри в `SHA256SUMS.txt`. Их можно сравнить с файлами из `npm pack stockfish@19.0.1` (папка `bin/`) или из релиза на GitHub.
